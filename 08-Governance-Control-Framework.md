# 08 — Governance Control Framework

## Preventive Controls
- Approved Copilot use policy
- User training
- Data classification guidance
- Prohibited-use list
- Permissions review
- Sensitivity labels
- Public-content approval
- Records-management guidance
- Restricted-topic rules
- AI inventory entry

## Detective Controls
- Review available interaction audit logs
- Spot-check AI outputs
- Review public-content drafts
- Monitor incidents
- Review meeting-summary corrections
- Track user feedback
- Track high-risk use cases
- Review permission issues

## Corrective Controls
- Correct inaccurate output
- Remove/revise public content
- Restrict sensitive-document access
- Update records
- Retrain users
- Update policies
- Escalate incidents
- Reassess affected use cases

```text
PREVENT → DETECT → CORRECT → REASSESS → IMPROVE
```

# 15 — Key Risks and Controls

| Priority Risk | Primary Control |
|---|---|
| Inaccurate/fabricated output | Human verification and source review |
| Sensitive data exposure | Data classification, training, access management |
| Oversharing from permissions | Permission review and least privilege |
| Over-reliance on AI | Training and mandatory review |
| Public content errors | Formal publication approval |
| Cultural misrepresentation | Curatorial/cultural review |
| Records governance failure | Records-owner review, retention, classification |
| Prompt injection/security risk | Security monitoring and incident response |

## Highest-Priority Controls
- Mandatory human validation
- Data classification
- Permission hygiene
- Public-content approval
- Curatorial review
- Records governance
- User training
- Monitoring and audit
- Incident response

> **AI supports professional judgment; it does not replace professional accountability.**

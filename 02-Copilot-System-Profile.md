# 02 — Microsoft 365 Copilot System Profile

## System
**Microsoft 365 Copilot**

## Type
Enterprise generative AI assistant integrated with Microsoft 365 services.

## Main Users
Knowledge workers, administrators, registrars, records staff, curators, collections staff, communications teams, project teams, and managers.

## Data Sources
Microsoft 365 content that an authorized user can access, including emails, chats, documents, meeting content, and productivity data.

## Governance Implications
Focus governance on permissions hygiene, data classification, sensitivity labels, retention, training, human review, public-content approval, monitoring, and audit.

## Governance Position
Copilot is an assistant and drafting tool, not an authoritative decision-maker. High-impact outputs require appropriate human review before official use.

# 02 · Copilot System Profile

| Field | Detail |
|---|---|
| **AI System Name** | Microsoft 365 Copilot |
| **AI System Type** | Enterprise generative AI assistant integrated with Microsoft 365 services |

## Public Product Description Used for Assessment

Microsoft describes Microsoft 365 Copilot as coordinating large language models, content in Microsoft Graph such as emails, chats, and documents that a user has permission to access, and Microsoft 365 productivity apps used every day.¹

## Main Users

Knowledge workers · Administrative staff · Registrars · Records staff · Curators · Collections staff · Communications staff · Project teams · Managers

## Main Data Sources

Based on Microsoft's public documentation, Microsoft 365 Copilot can use content in Microsoft Graph, including emails, chats, and documents that the user has permission to access.¹

## Key Governance Implication

Because Copilot can surface and summarize information the user has permission to access, governance should focus heavily on:

- Permissions hygiene
- Sensitivity labels
- Retention policies
- User training
- Human review
- Public-content approval
- Monitoring and audit

Microsoft states that Copilot respects identity models and permissions, inherits sensitivity labels, applies retention policies, supports audit of interactions, and follows administrative settings, depending on the subscription plan.²

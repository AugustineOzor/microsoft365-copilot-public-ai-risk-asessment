# 08 · Human Review Matrix

| Copilot Output | Required Reviewer |
|---|---|
| Internal email draft | User |
| Meeting summary | Meeting owner |
| Official minutes | Records owner or meeting owner |
| Object description | Registrar + curator |
| Metadata suggestion | Registrar or metadata specialist |
| Exhibition text | Curator + communications |
| Public website text | Communications + content owner |
| Translation draft | Translator + curator |
| Policy summary | Policy owner |
| Sensitive cultural content | Curator + specialist reviewer |

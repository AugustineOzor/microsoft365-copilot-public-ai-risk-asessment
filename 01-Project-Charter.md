# 01 · Project Charter

## Project Overview

This project creates a real-world AI governance risk assessment for Microsoft 365 Copilot as used in a workplace environment.

The project evaluates how Microsoft 365 Copilot may be used by museum, registrar, metadata, records, exhibitions, and administrative teams for:

- Drafting emails
- Summarizing meetings
- Searching internal documents
- Drafting object descriptions
- Improving metadata language
- Summarizing policy documents
- Creating presentation drafts
- Translating or adapting content
- Drafting public-facing communications
- Supporting records and documentation workflows

This project does **not** judge whether Microsoft 365 Copilot is "good" or "bad." Instead, it asks:

> If an organization uses Microsoft 365 Copilot, what risks should governance teams identify, what controls should be in place, and how should use be monitored?

## Why This Is a Real-World Project

This is a realistic AI governance project because many organizations are adopting Microsoft 365 Copilot before fully defining:

- Approved use cases
- Sensitive data rules
- Human review requirements
- Meeting-summary review workflows
- Public-content approval rules
- User training requirements
- Audit and monitoring processes
- Incident response procedures

Microsoft's Responsible AI FAQs note that they are intended to help users understand how AI technology works, the choices system owners and users can make that affect system performance and behavior, and the importance of considering the whole system — technology, people, and environment.¹ That framing is why this project treats Copilot governance as a **socio-technical operating model**, not only a product setting.

## Project Objective

The objective is to create a practical governance plan for safe, responsible, and auditable use of Microsoft 365 Copilot in a museum and records-management environment.

The project produces:

- AI system profile
- Copilot use-case inventory
- Risk register
- NIST AI RMF-aligned assessment
- Governance controls
- User policy rules
- Human review workflows
- Monitoring dashboard
- Incident response plan
- Audit checklist
- Final recommendation

## Scope

### In Scope

This assessment covers use of Microsoft 365 Copilot for:

- Drafting and rewriting internal content
- Summarizing meetings and documents
- Searching Microsoft 365 content
- Drafting metadata-related text
- Drafting public content before review
- Summarizing emails and chats
- Supporting productivity in Word, PowerPoint, Outlook, Teams, and related Microsoft 365 workflows

Microsoft states that Microsoft 365 Copilot coordinates large language models, Microsoft Graph content that a user has permission to access, and Microsoft 365 productivity apps such as Word and PowerPoint.²

### Out of Scope

This project does not include:

- Legal advice
- Technical penetration testing
- Microsoft tenant configuration instructions
- Licensing recommendations
- Actual deployment of Copilot
- Claims about your organization's internal configuration
- Evaluation of employee performance or productivity

# 05 — NIST AI RMF Mapping

## Govern
Define ownership, accountability, policies, responsibilities, risk tolerance, and review requirements.

## Map
Identify use cases, users, data, context, stakeholders, public impacts, and potential harms.

## Measure
Assess output accuracy, risk, incidents, bias, quality, metrics, and control effectiveness.

## Manage
Apply human oversight, monitoring, training, access controls, incident response, corrective actions, and periodic reassessment.

```text
GOVERN → MAP → MEASURE → MANAGE → CONTINUOUS IMPROVEMENT
```

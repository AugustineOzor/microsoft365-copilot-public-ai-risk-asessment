# 12 — Copilot Incident Response Plan

## Level 1 — Minor Output Issue
**Example:** Unclear wording or formatting error.
**Response:** Correct output; escalate only if repeated.

## Level 2 — Inaccurate Internal Output
**Example:** Incorrect meeting summary.
**Response:** Correct, notify owner, record if business-impacting, update checklist.

## Level 3 — Sensitive or Records-Impacting Issue
**Example:** Confidential information shared too broadly.
**Response:** Restrict access, notify owner, review permissions, correct/remove content, document root cause.

## Level 4 — Public, Legal, Privacy, or Reputational Incident
**Example:** Serious factual, cultural, or confidentiality issue in public content.
**Response:** Remove/correct, notify governance owner, escalate, preserve evidence, investigate, update controls and training.

```text
DETECT → CLASSIFY → CONTAIN → CORRECT → INVESTIGATE → DOCUMENT → IMPROVE
```

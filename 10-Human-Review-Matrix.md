# 10 — Human Review Matrix

| Output | Required Reviewer |
|---|---|
| Internal email draft | User |
| Meeting summary | Meeting owner |
| Official minutes | Records/meeting owner |
| Object description | Registrar + Curator |
| Metadata suggestion | Registrar/Metadata Specialist |
| Exhibition text | Curator + Communications |
| Public website text | Communications + Content Owner |
| Translation draft | Translator + Curator |
| Policy summary | Policy Owner |
| Sensitive cultural content | Curator + Specialist Reviewer |

Human review is mandatory where output affects official records, public information, collection metadata, cultural heritage, high-impact decisions, or sensitive information.
